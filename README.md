# Scoped Rejection with Contestable Dependency Closure

A candidate review semantics: rejections block exactly the sections they name; the remainder lands under an author-declared, reviewer-contestable dependency closure. Not a confirmed component of any system.

The single conceptual document is [SCOPED_REJECTION.md](SCOPED_REJECTION.md). Everything else in this repository is operational scaffolding and does not constitute additional conceptual specification.
